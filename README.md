# Netflex 🎬

A Netflix-inspired streaming web application built with Next.js, React, and TypeScript.

I built this project to practice creating a complete, responsive web application with reusable components, dynamic pages, user interactions, and a streaming-platform style interface.

## Live Demo

https://netflex-clone-olive.vercel.app/

## Features

- 🎬 Browse movies and TV shows
- 🔎 Search and explore content
- 📄 View movie and show information
- 🌐 Language / translation support
- 📱 Responsive design
- 🧩 Reusable React components
- 🎨 Netflix-inspired interface
- ⚡ Dynamic and interactive UI
- 🚀 Production deployment with Vercel

## Tech Stack

- Next.js 15
- React 19
- TypeScript
- HTML
- CSS
- Vercel
- Git & GitHub

## Why I Built This

I wanted to build something larger than a collection of individual UI pages.

The goal was to understand how different parts of a modern frontend application work together, from building reusable components and pages to handling user interactions and deploying the final application.

## What I Worked On

While building Netflex, I worked on:

- Building the application with Next.js
- Creating reusable React components
- Using TypeScript throughout the project
- Creating responsive layouts
- Building dynamic pages
- Working with user interactions
- Creating a streaming-platform style browsing experience
- Adding language/translation support
- Organizing the project into reusable parts
- Preparing the application for production
- Deploying the project using Vercel

## Translation

The application includes language/translation functionality that allows the interface to support different languages.

I implemented this as part of the project to practice making the UI more flexible and accessible to users with different language preferences.

## Responsive Design

The application is designed to work across different screen sizes, including:

- Desktop
- Tablet
- Mobile

The interface adapts to different screen sizes while keeping the main browsing experience consistent.
